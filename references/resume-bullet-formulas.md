# Resume Bullet Formulas

## Core Patterns

- Action + technology + scope + result
- Action + ownership + business outcome
- Action + scale + measurable impact
- Built X using Y to achieve Z
- Led X across Y teams or systems, improving Z

## Good Bullet Traits

- specific
- measurable when possible
- rooted in actual ownership
- understandable without internal jargon

## Weak Bullet Traits

- generic
- passive
- tool list without outcome
- unverifiable claim
- no business context

## Rewrite Checklist

- name the thing built or improved
- name the stack only if relevant
- show scale or scope
- show the result
- keep it honest
