# Career Positioning Builder

A reusable skill for turning a resume, tech stack, target job, or career goal into ATS-friendly career positioning and application materials.

[![skills.sh](https://skills.sh/b/nullagent07/career-positioning-builder)](https://skills.sh/nullagent07/career-positioning-builder)

## What it does

- analyzes resumes and tech stacks
- researches the target market before drafting the output
- suggests best-fit job titles
- builds ATS keyword maps
- rewrites resume bullets
- creates a market-standard golden CV when the user only provides a role
- creates US, UK, and EU resume or CV versions
- generates LinkedIn headlines and recruiter messages
- flags unsupported claims and weak positioning

## Install

```bash
npx skills add https://github.com/nullagent07/career-positioning-builder
```

## Example prompts

```text
Here is my resume. Tell me which roles I fit best and rewrite it for the US market.
```

```text
Create a golden CV for Senior iOS Engineer in the US.
```

```text
My stack is Python, FastAPI, PostgreSQL, Docker, OpenAI API. Position me for AI Engineer roles.
```

```text
Here is a job description. Adapt my resume for this role and build an ATS keyword map.
```
